The trace is a class function, so the element form says the class form exactly; it is NOT a restatement of U3's word-level leg (no word, no `ntr`, no `IsWord` in the statement).
- Hyperbolicity: `2 < rabs tr` = "|tr g| > 2" (the print S2 l. 89–90). `<` is `≤ ∧ ≠` on the exact real order; since a + b√5 = 0 only at a = b = 0 the order is antisymmetric on ℤ[φ], so this is the real strict inequality. `±I` (trace ±2) is excluded, as the print's "other than ±I" requires.
