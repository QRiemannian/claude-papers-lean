## The one definition — `Visited X v`: CARRIED (it is the printed search's reached-and-kept set)

Lean: `∀ p, p <+: v → p ≠ [] → ntr p ≤ X ∧ (p.length ≤ 2 ∨ ((p.length : ZPhi) + 1) * phi ≤ X)`.
- **The search it models.** The record's search, as SH-P2-1 l. 189 and PHASE-2-DEFINITIONS l. 11 state it and as the print states it (S5 l. 509–511: "a depth-first search over words through the syllable cap …, abandoning a prefix as soon as its trace exceeds X"), descends from the empty word and enters a child wb only if t(wb) ≤ X and its length is within the cap (impl-a §2 rule (i), l. 74: "child wb is entered only if t(wb) ≤ X and n + 1 ≤ K"). A node is reached exactly when every one of its non-empty prefixes was an entered child — i.e. passed both rules. That is `Visited` word for word; `<+:` is the prefix relation. The empty prefix (the root, tr I = 2) is exempt, as the search's root is. Since the cap is monotone in k, the per-prefix cap equals the cap at v's own length; no weakening.
- **The cap inside it.** `k ≤ 2 ∨ (k + 1)φ ≤ X` ⟺ `k ≤ max(2, ⌊X/φ⌋ − 1)` with ⌊X/φ⌋ the largest n with nφ ≤ X (impl-a l. 99): k ≤ ⌊X/φ⌋ − 1 ⟺ (k + 1)φ ≤ X since φ > 0; for X < φ the second disjunct is false and the max is 2. For X ≥ 3φ the disjunct k ≤ 2 is absorbed ((k + 1)φ ≤ 3φ ≤ X), so the same predicate is also the print's first form, cap ⌊X/φ⌋ − 1 (S5 l. 510). One definition carries both printed caps.
- **Not a convenient relative.** It is not impl-a's tighter search (FKM prenecklaces + rule (ii), impl-a l. 72–77): that is one instrument's own rule, proved in its README; the print states the plain trace-rule-plus-cap search and records only that "each of the two census instruments proves its own pruning rule before using it" (S5 l. 516–517). A search that reaches every rotation reaches the necklace representative the FKM walk enumerates. One observation, inert: `Visited` puts no alphabet clause on v (a list with a letter outside {1, …, 4} sees an identity block, U1's `P` default). `Visited` occurs only in `g5_u15_srch_visit`'s conclusion, where v is a rotation of an `IsWord`, so v is itself a word and the alphabet clause is supplied by the hypothesis.
